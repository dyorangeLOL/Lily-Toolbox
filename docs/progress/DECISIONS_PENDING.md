## Gate A 当前可审阅方案

依据工作流 §22「审核多 WebView/备用宿主的 Gate A ADR，确认最终浏览器架构」。[PR #4](https://github.com/dyorangeLOL/Lily-Toolbox/pull/4) 和 [ADR-017](../adr/ADR-017-browser-host.md) 提供具体方案与实际 Windows 11 证据：保留 Tauri Shell，在同窗口通过 Wry公开扩展共享WebView2环境并使用命名Profile；高层Tauri不管理这些原生子控件，需要适配层负责生命周期。

原生多标签、隔离、Portable、退出已通过试验；性能基线完整，最终冷/热P90为0.907/0.791秒；初轮热启动2.159秒的失败数据已保留，差异未归因，**没有要求放宽目标**。请确认是否采用该宿主基线；本次自审没有代替产品所有者批准Gate A。确认后才按已授权顺序继续WF-03；不执行UI设计。

# ADR-018 — WF-03 核心协议与本地存储

状态：实施中，待完整 Windows 验收。2026-10-21；映射既有 ADR-009/010/011、规范 §6–8，无技术架构变更。

Tauri 只开放有限的 core_dispatch，本地 main 前端需同时通过 capability、实际调用 WebView 来源和请求校验。API v1 的请求、响应、领域命令、模块清单和事件格式冻结在 [核心契约](../api-contracts/wf03-core.md) 及 Rust/TS 共享夹具；错误只带固定错误码和脱敏说明。借助自有状态与工作线程按需打开 SQLite，避免在主线程迁移或阻塞。

核心持有 SQLite Connection，不导出任意 SQL；开启 WAL/外键、参数绑定、3秒忙等待及迁移校验。两次迁移建立 settings/modules/audit_events/permission_grants 和迁移台账，所有待执行迁移同一事务，失败整体回滚。更高版本或修改过的迁移拒绝打开，不自动重建坏库。安装版使用应用本地数据目录；Portable 要求显式 portable.flag 和 app/data 布局，不可写即错误，不能静默回退。

只实现 modules.list/capabilities；其他六领域仅定义必要契约，缺实现返回 NOT_IMPLEMENTED，文件类缺授权先拒绝。模块注册只接受编译时内置清单，数据库内容不能增加第三方入口或权限。原生授权建立/撤销与审计写入使用同一事务；每次操作读取当前授权，拒绝路径越界、链接和 Junction。未来文件变更仍需句柄级防竞态；本阶段不承诺已实现文件动作、任务队列或插件安装。

选择 rusqlite bundled 而非常驻服务/ORM，版本和许可见核心契约。新增13个锁定包（含仅测试/其他目标依赖）；未更新原有依赖版本。不得把整个锁文件包数当作 Windows 运行时加载数，或从源码大小估算启动和内存成本。

回滚：撤销 WF-03 PR 可恢复 WF-02 Shell；本阶段测试均使用独立夹具目录，不删除数据库或做隐式降级。未来正式数据必须保留数据库及 WAL/SHM，使用受支持升级或先验证备份；不能将旧版本直接打开新 Schema。所有者审阅数据库/接口/权限边界的要求按工作流 §22 记录，不以自审代替所有者。
